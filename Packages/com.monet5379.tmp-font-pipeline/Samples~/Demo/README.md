# Demo (JSON + Warmup) sample

Package Manager에서 **Import**한 뒤 사용하는 **슬림** 예시입니다. 폰트·씬·Generated txt는 포함하지 않습니다. Noto SDF·Apply 프로필까지 필요하면 **Demo (Noto + Baked Atlas)** 샘플을 Import하세요.

- `SampleData/StringUI.json`, `StringDialogue.json` — Extract 창의 JSON Folder 예시
- `SampleFontWarmupTarget` — `IFontWarmupTarget` 최소 구현 (`FontRoleCatalog` 할당 필요)

Extract·Apply 경로는 호스트 프로젝트에서 지정합니다. 파이프라인 창: **Tools → TMP Font Pipeline → 창 열기**.
